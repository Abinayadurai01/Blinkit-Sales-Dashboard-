# Blinkit Sales Dashboard

## Project Overview

This project analyzes Blinkit's sales data using Power BI, Excel, SQL, and Python to create an interactive dashboard that provides insights into sales performance, customer purchasing behavior, and product trends. The dashboard helps monitor key business metrics and supports data-driven decision-making.

---

## Tools Used

- Power BI
- SQL
- Microsoft Excel
- Power Query
- DAX

---

## Project Objectives

- Clean and transform raw sales data
- Perform data quality checks and preprocessing
- Analyze product and outlet performance
- Build interactive Power BI dashboards
- Monitor key business KPIs
- Generate actionable business insights

---

## Key KPIs

- Total Sales
- Total Orders
- Average Sales
- Average Rating
- Number of Items Sold
- Outlet Performance
- Item Type Performance

---

## Dashboard Features

- Sales by Outlet Location
- Sales by Outlet Size
- Sales by Outlet Type
- Sales by Item Category
- Fat Content Analysis
- Year-wise Sales Trend
- Interactive Filters and Slicers
- KPI Cards and Charts

---

## Process

1. Imported the Blinkit sales dataset into Power BI.
2. Cleaned and transformed the data using Power Query.
3. Performed data validation and quality checks.
4. Created DAX measures for Sales, Orders, Ratings, and Average Sales.
5. Designed an interactive dashboard with KPI cards, charts, and slicers.
6. Analyzed sales trends and generated business insights.

---

## Key Insights

- Identified the highest-performing outlet types based on sales.
- Compared sales across different outlet locations and sizes.
- Analyzed customer preferences across product categories.
- Monitored yearly sales growth using trend analysis.
- Evaluated item performance using sales and customer ratings.
- Created an interactive dashboard for business reporting.
